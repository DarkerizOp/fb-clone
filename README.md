# 📘 Facebook Clone

This is a simple **Facebook Clone** website that I created while learning the basics of **Git** and **GitHub**. The main purpose of this project was to understand version control, repository management, and the GitHub workflow while building a basic front-end web application.

## 🚀 About the Project

The project replicates the basic user interface of Facebook using HTML and CSS. It is intended for educational purposes and does not include any backend functionality or database integration.

Through this project, I learned how to:
- Initialize a Git repository.
- Track and commit changes using Git.
- Push code to a GitHub repository.
- Create branches and manage versions.
- Write a proper README file.
- Organize project files for better maintainability.

## ✨ Features

- Facebook-inspired homepage layout
- Responsive design (basic)
- Navigation bar
- Login form
- News feed section
- Sidebar layout
- Footer section
- Clean and simple user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- Git
- GitHub
